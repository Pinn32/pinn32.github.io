# 急、焦虑、生气

比起之前的悲伤、忧郁派的焦虑，我今天（或者最近）感到更偏向急切、恼羞成怒派焦虑。悲伤和忧郁会令人自我怀疑，降低欲望，阻碍人的行动；而愤怒和急切会让加重人对结果的渴望，但伴随着行动过快，失去耐心，操之过急。进而，我领悟到，**越慢的人越快，道理类同龟兔赛跑。**

# 恶性循环的陷阱

如题，我已经深刻体会到：忧郁、畏难和逃避互相促成的恶性循环会让人停滞不前——比较 → 自卑 → 忧郁 → 畏难 → 逃避 → 停滞 → 比较；而愤怒、急切和放弃引发的恶性循环会让人三分钟热度——比较 → 嫉妒 → 愤怒 → 急切 → 操之过急 → 短期不见成果 → 放弃。

从二图可以看出，忧郁和愤怒都有可能来源于比较。比较是一把双刃剑：良好的比较是明镜，可以提醒人自己所处的位置，甚至可能带来启发，激励人进行新的尝试；过度的比较是沼泽，诱发或自卑或嫉妒等情绪，进而阻碍人的行动，就像“我走在街上好好的，你飞来骂我一顿又走了”。

# 静心、稳步 ≠ 停滞、逃避

何为“越慢的人越快”？龟兔赛跑的故事大家都知道，但很难感同身受，毕竟它使用了拟人的动物为背景，而且读者不一定能立刻把“赛跑”联系到生活中的其他事上。其实这一道理在生活中也有所体现，比如练琴、练画：

1. 人很容易急于求成，于是在练琴初时就想要以原曲速度跟练；然而速度过快，一定会弹错，错弹重复几百遍，会浪费更多的时间在训练错误的肌肉记忆上，其效果反而不如以足够慢但没有弹错的速度重复几十遍；
2. 练画时，人很容易选择凭空开始画自己想画的，而不是临摹、观察和学习基本功，因为画画的目标是凭空画出自己想要的，不想停下来打基础，每次都想直接画成图，也是一种急于求成；道理和弹琴一样，如果没有临摹的观察练习，很难练出正确结构的肌肉记忆，而在没有打好基础时凭空画一百张图，也可能只是重复错误的肌肉记忆，难以进步。

由此可见，欲速则不达，急于求成不仅降低了效率，还容易增加心理压力，徒增烦恼。

“慢”不等于“停”。还记得高中时曾在练习册上看到一句话：“I’m a slow walker, but I never walk backwards”。静心和逃避，是容易混淆，实则完全不同的两种状态。“越慢的人越快”所指的慢，是不为外界所干扰，不被影响心境，坚持每天稳步前进；而不是因为不想再面对焦虑了而逃避成长，进而摆烂。不为外界所动，每天稳步前进的源动力并非对于宏大成就的极度渴望，也非比较产生的同辈压力和惧怕落后（FOMO，fear of missing out），而是专注于眼前的小事。全靠焦虑和惧怕落后这类负面情绪驱动的行动，难以持久延续，还容易反噬，负面情绪积少成多，可能反映在生活和人际关系中，也可能在未来爆发导致行动骤停和摆烂。要想维持长久的稳步行动，还得靠好奇心、兴趣、成就感、自我价值体现等正面情绪反馈。而学习感兴趣的内容，或每日完成简单上手的小任务，能够带来小但即时的正反馈，积少成多，及时每日只有少量正反馈，也会引领你进入正反馈循环。如《原子习惯》中所说，所有微小改进的总和，其影响可能大得超乎你想象。如果聚焦于庞大的最终成就，在达到成就前，每日都没有达到成就，可能产生一定的负面反馈；反之如果**专注于完成每日的小任务，且以好奇心（而非功利心）驱动求学和实践，才能持续产生正反馈。**

# 话语的力量

今日我将“反思”标签改为“思考”。虽然我自认为此标签的初衷并非负面的自我检讨，而是对事物的观察思考，但“反思”二字容易潜移默化地产生自己做错了需要检讨的印象，于是改为“思考”。

# 输出和复盘带来的平静

今日刚写此篇思考的过程，帮我 1）意识到情绪，开始思考其中逻辑，进而 2）恢复平静，专注眼前事。可见，输出确实会助人整理思路，恢复理智，增强逻辑。即使只是随手记录，任何小输出都比没有输出要好。
