长时间使用电脑时，我会优先减少手指和手腕的移动距离，并尽量让双手分担操作。下面是我目前在 Mac 上采用的几项调整。它们来自个人使用体验，不是通用的人体工学或医疗建议；设备、桌面高度和个人习惯不同，合适的设置也会不同。

# 提高鼠标指针速度

我使用外接鼠标，将 macOS 的鼠标速度调至最快，再通过 Logi Options+ 继续提高指针速度。与触控板手势相比，这样只需较小的手臂动作便能移动较远的光标，手指和手腕的活动幅度也更小。

外接鼠标的位置可以随时调整。我不必让右肘长时间保持同一个弯曲角度，需要时可以伸展手臂，变换姿势。

# 把常用操作放到鼠标侧键

我的鼠标有四个可自定义按键，分别用于拷贝、粘贴、删除和创建副本。Logi Options+ 支持针对不同应用单独配置，因此在视频剪辑、绘图或音乐软件中，也可以把这些按键替换为更常用的专属快捷键。

Mac Mouse Fix 等第三方工具还能设置长按、双击等操作，但它与 Logi Options+ 可能冲突。现有配置已经够用，所以我暂时没有叠加更多工具。

# 左手使用触控板

MacBook 的触控板紧邻键盘。打字过程中需要短暂移动光标时，我会直接用左手操作触控板，不必把右手在键盘和鼠标之间来回移动。

外接鼠标和内置触控板并不冲突：右手负责持续、精确的指针操作，左手负责输入间隙中的快速调整。

# 用左手拇指按空格

空格键使用频率很高，我改用左手拇指按。这个调整几乎没有学习成本，却能把一部分重复动作从右手转移到左手。

# 将 Caps Lock 映射为 Delete

我把 Caps Lock 映射为退格删除键。左手小拇指无需离开主键区便能删除文字，比伸手按键盘右上角的 Delete 更省距离，也进一步减少了右手的工作量。

大写字母仍然通过 `Shift + 字母` 输入；我的中英文切换也设置在 Shift 上。原来的 Delete 键继续保留，需要向前删除时可以按 `Fn + Delete`。如果很少使用原键，也可以把它改成其他快捷操作。

# 使用双拼输入

双拼把每个汉字的声母和韵母分别映射到一个按键。熟悉键位后，大多数拼音只需按两次，与全拼相比明显减少击键次数，也能提高中文输入速度。

切换双拼需要一段适应期，但这是我目前感受最明显的输入优化之一。

# 用软件快捷方式补充

除了硬件和按键调整，我也会使用 Raycast、应用内快捷键、macOS 自定义快捷键，以及 Automator 或「快捷指令」自动化重复操作。这些工具同样可以减少点击和键盘操作，不过更偏向软件工作流，之后再单独整理。

# 调整思路

这些设置的共同目标很简单：缩短高频操作的移动距离，避免同一只手持续承担所有动作。与其照搬一套固定配置，不如先观察自己最常重复、最容易疲劳的动作，再逐项调整鼠标速度、按键位置和左右手分工。
