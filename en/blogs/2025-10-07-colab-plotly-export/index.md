# Summary
## Problem
After editing an ipynb file in Google Colab and exporting it to HTML, the Plotly charts fail to display.


## Solution
After testing, in Google Colab the **ipynb file** [^1] behaves as follows:

- `fig.show()` displays the chart correctly.
- `fig.show(renderer="notebook_connected")` fails to display the chart.

But once exported to **HTML** [^2] and opened in a browser:

- Charts generated by `fig.show()` fail to display.
- Only charts generated by `fig.show(renderer="notebook_connected")` display correctly.

So when editing a notebook in Colab, use the default renderer (`fig.show()`), and switch the `renderer` to `"notebook_connected"` right before exporting to HTML.

## Notes
After editing an ipynb file in Colab, if you want to export it to HTML, be sure to press **Ctrl+S** first (saving to Google Drive) so that you export the most recently saved version. If you run the export command without saving first, the exported HTML may not be the latest version, and it may even have missing content or other issues.

**Recommended workflow:**

1. Finish editing the entire ipynb file.
2. Choose **Runtime → Restart and run all**.
3. Press **Ctrl+S** to save the notebook.
4. Run the code below **in another notebook** to export the HTML.

```bash
%%shell
jupyter nbconvert --to html /content/drive/MyDrive/path/filename.ipynb
```
