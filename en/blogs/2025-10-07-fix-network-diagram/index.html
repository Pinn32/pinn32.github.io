Network Diagram Display in Google Colab

Display a Pyvis network diagram both in Colab and the exported notebook HTML, without dependencies.
Author

Pinn Xu

Published

October 7, 2025

3 min read · 496 EN words · 0 中文字

1 Problem

A pyvis network diagram should display both inside Google Colab and in the HTML file exported from the notebook, without relying on a separate net.html file or other dependencies. None of the usual display methods handles all of these cases at once.

2 Solution

Call Network() without parameters, generate the diagram’s HTML manually, and wrap it in an iframe through the srcdoc attribute. Since the srcdoc value is delimited by single quotes, replace all single quotes in the generated HTML with double quotes first.

This method works everywhere the notebook renders: Jupyter, Colab 1, the exported HTML 2, and even VS Code.

# create an empty network diagram
gp = Network()  # don't specify parameters
# add network relation to the diagram
gp.from_nx(gx)

# store whole html code of the network diagram
html = gp.generate_html()
# format: only use double quotes
html_formatted = html.replace("'", '"')

# defining iframe tag
iframe_start = """
<iframe
style='display:block; margin:0px; width:100%; height:600px'
frameborder='0'
srcdoc='
"""
iframe_end = " '></iframe> "

# wrap formatted html code with iframe tag
html_wrapped = iframe_start + html_formatted + iframe_end

# display
display(HTML(html_wrapped))

3 Other Methods and Their Drawbacks

The alternatives require specifying notebook and cdn_resources when calling Network():

gp = Network(
    notebook=True,
    cdn_resources="in_line",
    height="600px",
    width="100%",
)
gp.from_nx(gx)

Each display method then fails somewhere:

  1. display(HTML(gp.generate_html())) renders the diagram in Colab without creating external network files, but the diagram is missing from the exported HTML.
  2. gp.show("net.html") renders the diagram in Jupyter but not in Colab.
  3. All generate_html(), save_graph(), and gp.show("net.html") followed by display(HTML(...)) renders correctly in Colab, but depends on the separate net.html file or libs/ folder of dependencies.

# Problem
A pyvis network diagram should display both inside Google Colab and in the HTML file exported from the notebook, without relying on a separate `net.html` file or other dependencies. None of the usual display methods handles all of these cases at once.

# Solution
Call `Network()` without parameters, generate the diagram's HTML manually, and wrap it in an iframe through the `srcdoc` attribute. Since the `srcdoc` value is delimited by single quotes, replace all single quotes in the generated HTML with double quotes first.

This method works everywhere the notebook renders: Jupyter, Colab [^1], the exported HTML [^2], and even VS Code.

[^1]: **IPYNB file:** View the [demo file in Colab](https://drive.google.com/file/d/15vy8hmaq_3KK-T9p-TdeNfxfmwPP9V30/view?usp=sharing) or <a href="../../../src/data/fix-network-diagram/network-test.ipynb" download>download it</a>

[^2]: **HTML file:** View the [demo file in the browser](../../../src/data/fix-network-diagram/network-test.html) or <a href="../../../src/data/fix-network-diagram/network-test.html" download>download it</a>

# create an empty network diagram
gp = Network()  # don't specify parameters
# add network relation to the diagram
gp.from_nx(gx)

# store whole html code of the network diagram
html = gp.generate_html()

html_formatted = html.replace("'", '"')

# Other Methods and Their Drawbacks
The alternatives require specifying `notebook` and `cdn_resources` when calling `Network()`:

```{python}
#| eval: false
gp = Network(
    notebook=True,
    cdn_resources="in_line",
    height="600px",
    width="100%",
)
gp.from_nx(gx)
```

Each display method then fails somewhere:

1. `display(HTML(gp.generate_html()))` renders the diagram in Colab without creating external network files, but the diagram is missing from the exported HTML.
2. `gp.show("net.html")` renders the diagram in Jupyter but not in Colab.
3. All `generate_html()`, `save_graph()`, and `gp.show("net.html")` followed by `display(HTML(...))` renders correctly in Colab, but depends on the separate `net.html` file or `libs/` folder of dependencies.
